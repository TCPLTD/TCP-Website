# Town & Country Planning Ltd website

Static website for townandcountryplanningltd.co.uk, built to be hosted free on GitHub Pages.

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home |
| `projects.html` | Project gallery with search and filters |
| `map.html` | Map of approved projects |
| `services.html` | Services |
| `process.html` | How we work (five steps) and FAQ |
| `fees.html` | Design fee estimator |
| `about.html` | About, team and testimonials |
| `contact.html` | Contact details and enquiry form |

`gallery.html` and `faq.html` redirect to the new pages so old links keep working.

## Editing

- **Pages:** generated by `python3 tools/build_pages.py .` (shared header, footer and text live in that script). Edit the script and re-run it rather than editing the HTML by hand.
- **Projects (gallery and map):** `data/projects.js`. One entry per approved job. Street and town only, never house numbers or client names. `lat`/`lng` should be on the street, not the house.
- **Fee prices:** the `PRICES` table at the top of `js/fees.js`. `null` shows "We'll quote by phone".
- **Styles:** `css/site.css` (colours are tokens at the top).
- **Map:** Leaflet 1.9.4 is bundled in `js/vendor` and `css/vendor`; map tiles come from OpenStreetMap.
